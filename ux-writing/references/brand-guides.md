# 5개 브랜드 라이팅 가이드라인과 공통점

개선 근거를 댈 때 인용한다. 각 사의 공개 가이드라인을 요약한 것이며 원문은 해당 브랜드 문서를 참고한다.

## 토스 — 5원칙
| 원칙 | 체크 질문 |
|---|---|
| Clear 명확한 | 다음 화면을 예상할 힌트가 있는가? 정말 중요한 메시지만 전달하는가? |
| Concise 간결한 | 의미 없는 단어·문장을 모두 제거했는가? |
| Casual 친근한 | 이해하기 어려운 용어·표현을 쓰지 않았는가? 모두가 이해하고 무해한 단어인가? |
| Respect 존중하는 | 행동을 강요하거나 공포감을 주지 않는가? (Suggest, not force) |
| Emotional 공감하는 | 정보 전달을 넘어 사용자의 감정에 공감했는가? |

## 뉴닉 — 4원칙 (뉴스레터·콘텐츠)
- **진심으로 전한다**: 남 얘기하듯 쓰지 않고, 독자의 일상과 관심사에 맞닿게.
- **재미있게 대화한다**: 친구에게 말하듯 입말로, 한자어·어려운 말은 풀어서, 빙빙 돌리지 않고 두괄식, 질문했으면 답이 바로.
- **판단할 권리를 존중한다**: 의견을 단언하지 않고 양쪽 입장 분량을 고르게, 생생한 의견은 큰따옴표로 인용.
- **누구도 상처 주지 않는다**: 오해·편견을 일으키는 표현 금지, 소수자 관점에서 점검.

## 숨고 — 5원칙 (Clarity · Concise · Consistency · Positive · Be Nice)
- 누구나 이해할 수 있게 쉽게, 전문·회사 용어 지양(예: "요청서" 같은 내부 명칭)
- 가장 중요한 단어를 포함한 필수 세부사항만, 길게 서술하지 않기
- "~해요"체 기본, 어색할 때만 "~합니다"체 / 디자인 시스템 내 규칙 준수
- 경고·주의·부정 어조 대신 사용자가 얻는 이점·혜택 명시
- 사용자로서 봤을 때 거부감(조급함)이 없고 배려받는 느낌으로 자연스럽게 이해되는가

## 구글 Material — Writing
- **글로벌하게**: 특정 문화권 참조를 피하거나 설명하고, 모두가 이해하고 상처받지 않게.
- **결과를 설명**: 중립적·직접적 언어로 행동의 결과를 알리되, 위협적·거만한 경고 금지. 기능의 결과 전달에 집중.
- **스캔 가능하게**: 주제를 명확히 드러내는 제목·표제, 위계와 읽는 순서를 고려.

## 애플 HIG — Writing
- **명확하게**: 이해하기 쉽고 올바른 단어. 더 적은 단어로 가능하면 그렇게.
- **모두를 위해**: 쉬운 언어, 전문 용어와 성별 편향 용어 회피, 접근성·현지화 고려.
- **화면 목적 중심**: 가장 중요한 정보를 먼저. 두 가지 이상 아이디어면 화면을 나누고 전체 흐름을 설계.
- **행동 지향**: 버튼·링크 라벨은 거의 항상 동사. 귀엽거나 영리한 라벨보다 명확성 우선.

## 5개 브랜드의 공통점 (→ 이 스킬의 4대 가이드라인으로 압축)
1. **간결** — 중요한 것 먼저, 군말 제거
2. **명확** — 쉽게, 애매함 없이, 한 화면에 메시지 하나, 다음 화면 힌트
3. **모두를 위한 글쓰기** — 상처·오해 없이, 부정·공포 대신 긍정, 선택권 존중
4. **혜택·결과·유저 입장** — 사용자가 얻는 것과 일어날 일을 보여주기
