# UX 라이팅 체크리스트

문구를 확정하기 전에 훑는다. "아니오"가 나오면 해당 항목의 원칙(`guidelines.md`)으로 돌아간다.

## 간결
- [ ] 극존칭·과잉 경어("~하시겠습니까")를 뺐는가?
- [ ] 같은 뜻의 문장이 두 번 나오지 않는가?
- [ ] 화면에 이미 보이거나 당연한 정보를 문장으로 반복하지 않는가?
- [ ] 줄이면서 핵심 정보(무엇을, 얼마나, 언제)가 빠지지는 않았는가?

## 명확
- [ ] 소리 내어 읽었을 때 자연스러운가?
- [ ] 한자어·영어·내부 용어·회사 용어가 남아 있지 않은가?
- [ ] 한 문장에 메시지가 하나인가? 다의어로 오해될 단어는 없는가?
- [ ] 가장 중요한 정보가 첫 문장에 있는가(두괄식)?
- [ ] 질문형 제목이면 답이 바로 이어지는가?
- [ ] "취소"를 진짜 되돌리는 행위에만 썼는가?
- [ ] 타이틀과 버튼 문구가 서로 호응하는가?
- [ ] 타이틀이 "안내/알림" 같은 빈 말이 아니라 사건 자체인가?
- [ ] 타이틀+본문 전체에서 질문이 한 번만 나오는가?
- [ ] 숫자·수량·시간으로 구체화할 수 있는 부분을 구체화했는가?
- [ ] 버튼을 누른 뒤 어떤 화면이 나올지 예상되는가?

## 모두를 위해
- [ ] 공급자만 아는 맥락을 전제하지 않았는가?
- [ ] 첫 진입 화면에 브랜드명·이벤트명·낯선 용어가 없는가?
- [ ] 특정 집단만 아는 유행어·은어에 의존하지 않는가?
- [ ] 누구도 상처받지 않을 표현인가?
- [ ] 강요·공포·조급함을 주는 어감이 없는가?
- [ ] 메인 버튼이 사용자 기대(또는 의도한 목표)와 맞는가?
- [ ] 에러·거절 메시지라면 "그래서 무엇을 하면 되는지"가 있는가?

## 전환
- [ ] 사용자가 얻는 혜택·결과가 보이는가?
- [ ] 불확실한 큰 혜택보다 확실한 작은 혜택을 앞세웠는가?
- [ ] 광고 냄새 대신 기능·정보·뉴스처럼 읽히는가?
- [ ] 소요 시간·비용 등 걱정 포인트를 선제적으로 해소했는가?
- [ ] 왜 지금 해야 하는지 이유가 한 줄 있는가?

## 일관성
- [ ] 프로젝트의 기존 어미·용어·톤과 일치하는가?
- [ ] 같은 개념을 화면마다 다른 단어로 부르지 않는가?
